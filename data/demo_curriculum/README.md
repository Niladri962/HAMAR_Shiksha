# Demonstration curriculum (NOT SCERT material)

These short primers were written for the HAMAR SHIKSHA demonstration only. They
exercise the ingestion, retrieval and citation pipeline. They are **not**
SCERT Chhattisgarh textbooks, have not been reviewed by SCERT, and must not be
used for teaching.

Replace them with authorised SCERT PDFs via
`python -m app.cli ingest-curriculum <manifest.json>` (see docs/TECHNICAL.md).
`manifest.json` shows the metadata format.
